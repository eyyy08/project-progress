## Project Overview

> Briefly describe your project idea, what problem it solves, and what you aim to build.

WearIt is a personal wardrobe web app. Many people own lots of clothes but struggle to decide what to wear each day. WearIt lets users catalogue their clothes and press a button to get a random outfit suggestion. I aim to build it with HTML, CSS, PHP and MySQL, including a login system with three roles and a database with linked tables.
